# Work Hours

Это консольный Rogue-like с хоррор тематикой. Код игры разделён на два модуля: движок с основной логикой и клиент, содержащий UI игрока и обработку ввода/вывода. Управление на клавиатуру и мышь.

Фичи:

## 1) Инвентарь

Карманы игрока ограничены по размеру, а также имеется два слота левой и правой руки. В них можно либо держать больше полезных предметов, либо оружие / фонарик. Оружие бывает в две и в одну руку (нож/топор). Из пистолета можно стрелять на расстоянии, пока есть, чем его перезаряжать. Бинты можно использовать на себе, чтобы лечиться.

## 2) Лут

Наводя на клетки можно посмотреть, что в них находится. Ненужные предметы можно выкинуть и они останутся на земле

## 3) Яйца монстров и монстры

Монстры блуждают когда не видят игрока и идут на него, если он поблизости и в поле зрения.
![workhours1](https://github.com/user-attachments/assets/b31685f0-2904-4adf-8f2a-b33b6507c29b)

## 4) Бой / Перемещение

Бой ведётся пошагово. Ход игрока - ход монстров. У игрока есть определенное кол-во здоровья и выносливости. За счёт выносливости можно бежать быстрее монстров, но недолго.

## 5) Баррикадирование

Столы и стулья можно переставлять, чтобы создавать баррикады, задерживающие монстров

## 6) FOV / освещение

Лампочки можно использовать на разбитых лампах чтобы зажечь их.
